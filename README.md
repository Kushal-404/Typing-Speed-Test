# ⌨️ Typing Speed Test

A clean, interactive web application designed to measure and improve typing speed and accuracy. This project provides users with real-time feedback on their Words Per Minute (WPM), keystroke accuracy, and error rates, making it an excellent tool for daily typing practice.

## ✨ Features

*   **Real-time WPM Calculation:** Tracks your Words Per Minute dynamically as you type.
*   **Accuracy Tracking:** Calculates the percentage of correct keystrokes versus errors.
*   **Countdown Timer:** Challenge yourself against a set time limit (e.g., 60 seconds).
*   **Clean UI/UX:** A minimalist, distraction-free interface built for focus.
*   **Instant Reset:** Quickly restart the test with a new prompt.
